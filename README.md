# Dining Meal Booking System

A simple **Node.js command-line application** for creating and managing dining meal bookings. The application demonstrates **Object-Oriented Programming (OOP)** concepts in JavaScript, including classes, private fields, constructors, getters, setters, validation, and methods.

---

## 📖 Project Description

This project allows users to create and manage meal bookings through the command line. Users enter student information, choose a meal type, specify the quantity, and optionally include dietary notes. The application validates the input, calculates the total meal cost, and displays a booking summary.

The project contains two JavaScript files:

- **DiningApp.js** – Handles user interaction and application execution.
- **MealBooking.js** – Defines the `MealBooking` class and manages booking information.

---

## ✨ Features

- Create a meal booking
- Store student information
- Select meal type
- Specify meal quantity
- Add dietary notes
- Validate user input
- Calculate total meal cost
- Display booking summary

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/dining-meal-booking.git
```

### Go to the project folder

```bash
cd dining-meal-booking
```

### Install Node.js

Download and install Node.js from:

https://nodejs.org/

---

## ▶️ Running the Application

Run the following command:

```bash
node DiningApp.js
```
